STAC Hub — открытые геоданные (плагин для QGIS 3.22–3.4x)
==========================================================

Единая точка доступа к открытым геоданным по протоколу STAC:
12 каталогов + 76 флагманских наборов NASA CMR-STAC в одном окне.
RGB-синтезы и спектральные индексы для мультиспектральных снимков
в один клик (без скачивания — всё через COG-стриминг).

УСТАНОВКА
---------
1. QGIS: «Модули» → «Управление модулями…» → «Установить из ZIP».
2. Выберите файл STAC_Hub_qgis_plugin.zip.
3. Появится кнопка STAC Hub на веб-панели инструментов и пункт меню
   «Web → STAC Hub». Экспериментальные модули должны быть разрешены:
   «Управление модулями → Настройки → Показывать экспериментальные модули».

ИСТОЧНИКИ
---------
- EarthSearch (Element 84 / AWS)      — Sentinel-2, Landsat, NAIP, Copernicus DEM
- USGS LandsatLook                    — Landsat C2 L2/ARD/DSWE/fSCA (анонимно)
- Copernicus Data Space               — Sentinel-1/2/3/5P, CLMS
- Terrascope (VITO)                   — Sentinel, PROBA-V, CLMS
- Microsoft Planetary Computer        — Sentinel-1/2, HLS, Sentinel-5P/3,
  DEM, климат, LULC (136 коллекций; SAS-подпись автоматически)
- NASA CMR-STAC (61 провайдер)        — 76 встроенных флагманских наборов:
  HLS, EMIT, GEDI, ECOSTRESS, SRTM/NASADEM, MODIS/VIIRS, IMERG, MERRA-2,
  OCO-2/3, ICESat-2, GRACE-FO, OPERA, Sentinel-1, хлорофилл, Black Marble…
- Vantor Open Data (бывш. Maxar)      — катастрофы 2026, 0.3–0.6 м, CC BY-NC 4.0
- Maxar Open Data (архив)             — катастрофы 2023–2025
- Umbra Open Data                     — SAR 25 см, открытые сюжеты
- Digital Earth Africa / Australia    — региональные платформы
- Brazil Data Cube                    — кубы данных Sentinel/Landsat

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. «Взять экстент карты» — подставить текущий вид; или задайте BBox руками;
   «Весь мир» — снять ограничение.
2. При необходимости: интервал дат, максимум облачности, лимит на источник.
3. Отметьте нужные источники в дереве (группировка: по категориям или по охвату).
4. «Найти» — один запрос расходится по всем отмеченным источникам.
5. Результаты: выберите «Отображение» и нажмите «Добавить слой»
   (или двойной клик — возьмётся выбранный вариант).

ОТОБРАЖЕНИЕ (СИНТЕЗЫ И ИНДЕКСЫ)
-------------------------------
Для мультиспектральных снимков (Sentinel-2, Landsat, MODIS, NAIP, HLS…)
доступны варианты:
- Истинный цвет (RGB) и «как есть»;
- Ложный цвет (NIR–R–G) — растительность красным;
- SWIR (SWIR1–NIR–R), Сельское хозяйство (SWIR1–NIR–B),
  Геология (SWIR1–SWIR2–B), Городская застройка (SWIR2–NIR–R);
- Индексы: NDVI (вегетация), NDWI (вода), NDBI (застройка),
  NBR (выгорание) — считаются по текущему экстенту карты,
  результат — GeoTIFF с палитрой в %TEMP%/stac_hub_indices.
Каналы берутся из ассетов айтема (eo:bands) и склеиваются виртуальной
VRT-мозаикой (/vsicurl/, без скачивания). Для снимков без нужных каналов
(SAR, DEM, тематические) список сокращается автоматически.

УЧЁТНЫЕ ДАННЫЕ
--------------
Кнопка «Учётные данные…»:
- NASA CMR-STAC: бесплатный Earthdata Login (urs.earthdata.nasa.gov) —
  Basic (логин/пароль) или Bearer-токен LP DAAC;
- Copernicus Data Space: Bearer-токен с account.dataspace.copernicus.eu;
- Terrascope: логин/пароль бесплатного аккаунта;
- Planetary Computer: ключ API в заголовке Ocp-Apim-Subscription-Key
  (режим «Заголовок»).

Галочка «Запомнить» сохраняет данные в настройках QGIS (QSettings, без
шифрования). Без неё данные живут до закрытия QGIS.

ОСОБЕННОСТИ И ОГОВОРКИ
----------------------
- Авторизация для загрузки применяется через GDAL-конфигурацию
  (GDAL_HTTP_AUTH/GDAL_HTTP_USERPWD/GDAL_HTTP_HEADERS) и действует в пределах
  сессии QGIS.
- DE Africa: эндпоинт /search периодически недоступен на стороне сервера —
  источник оставлен, ошибки поиска показываются в строке статуса.
- Planetary Computer: ключ API не нужен — плагин сам подписывает ссылки
  SAS-токеном коллекции (кэш 45 мин); ключ Ocp-Apim-Subscription-Key
  (режим «Заголовок») — опционально при больших объёмах.
- Статические каталоги (Vantor/Maxar/Umbra) обходятся локально: поиск идёт
  по подкаталогам с лимитами, поэтому большие каталоги могут отдавать не
  все совпадения.
- CMR-STAC ищет по 9 ключевым провайдерам, если не отмечены конкретные
  коллекции; при отмеченных коллекциях — только по их провайдерам.

Проверка источников выполнена 10.09.2026 живыми запросами (поиск, ассеты,
COG-стриминг, SAS-подпись). Версия 0.1.3, экспериментальная.
